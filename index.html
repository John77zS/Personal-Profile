Web institucional / Evento académico

Web académica / Congreso internacional

Web de evento / Innovación y emprendimiento

Sitio Web Hackathon UTEPSA 2024

Web institucional / Evento universitario

Sitio Web JETS UTEPSA 2024

Sitio web desarrollado para presentar la información general del JETS 2024, incluyendo descripción del evento, speakers, convocatorias, eventos especiales, programa, galería, inscripciones y datos de contacto.

Sistema web / Punto de venta

CambaClothes - Sistema POS

Aplicación web tipo POS para la administración de una tienda de ropa, orientada a gestionar operaciones internas desde un panel privado. El sistema cuenta con autenticación de usuarios, estructura de dashboard y funcionalidades enfocadas en la organización y control de datos comerciales.

Aplicación móvil

Maps App

Aplicación móvil con Flutter y Dart orientada al registro, visualización y gestión de ubicaciones importantes en un mapa interactivo.

Inteligencia Artificial

Predicción de rotación de personal

Modelo predictivo trabajado con Python, Google Colab, Scikit-learn y Streamlit para estimar riesgo de renuncia de empleados.

Machine Learning / Procesamiento de Lenguaje Natural

Clasificador de Reseñas Falsas

Proyecto académico basado en procesamiento de lenguaje natural para clasificar reseñas como verdaderas o falsas. Se aplicó limpieza de texto, eliminación de stopwords, vectorización y entrenamiento de modelos supervisados para evaluar el comportamiento del sistema.

Inteligencia Artificial / Análisis Predictivo

Sistema de Pronóstico de Ventas

Proyecto académico enfocado en el pronóstico de ventas para tiendas de farmacia, utilizando datos históricos para analizar patrones, preparar variables y construir modelos predictivos que apoyen la toma de decisiones comerciales.

Desarrollo Web / Chatbot

Bot de Preguntas para Sitio Web

Componente web tipo chatbot creado para integrarse en páginas empresariales, con burbuja flotante, animaciones, mensaje automático y estructura preparada para responder preguntas frecuentes mediante palabras clave.

Desarrollo Web / Propuesta Institucional

Propuesta Web Monterrey SRL

Sitio web desarrollado como propuesta digital para Monterrey SRL, empresa orientada a soluciones en acero para construcción, industria, agropecuaria y metalmecánica. La página integra secciones institucionales, productos destacados, galería, comunicados, testimonios, contacto, mapa de sucursales y asistente virtual.
